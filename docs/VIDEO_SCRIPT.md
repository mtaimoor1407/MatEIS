# Video documentation script (3–4 minutes)

**Setup:** screen recorder (OBS or Windows Game Bar), 1080p, microphone check, browser zoom 110%, deployed app open. Do one dry run, then record. Keep it under 4 minutes.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Title card or app home | "This is MatEIS Select, built for CSC-214. It helps engineers choose a material for a design objective." |
| 0:20 | Sidebar | "I start with constraints. Here I require a minimum strength of 200 megapascals." |
| 0:45 | Objective dropdown | "Next the objective. Light, stiff beam uses the index E to the half over density. Higher is better." |
| 1:10 | Chart | "The star is the best material. The dashed line has constant index value; anything above it is better." Hover a point to show the tooltip. |
| 1:40 | Ranked table, details | "The table ranks all candidates. The details panel shows specific stiffness, source and whether the data is verified." |
| 2:10 | Switch to cheap objective | "If cost matters, the best material changes." |
| 2:30 | Impossible filter | "Impossible limits give a clear warning instead of an error." |
| 2:45 | Export | "I can download a CSV or build a PDF report." Open the PDF. |
| 3:10 | Database tab | "Materials can be added, edited and marked verified. Bad values are rejected." |
| 3:40 | Close | "The code is modular, has 166 tests, and is deployed at this link. Thank you." |

Checklist: names of all team members said or shown · deployed URL visible · no errors on screen · audio clear · file under the size limit your instructor allows.
